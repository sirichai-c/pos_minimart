# บ้านดี POS — interactive mockup

หน้าเว็บตัวอย่างภาษาไทย อ้างอิง `../plan/pos-mvp-spec.md` และ `../plan/pos-returns-refunds-spec.md` ใช้ทดลอง flow และทบทวนหน้าจอก่อนพัฒนาระบบจริง

## เปิดใช้งาน

เปิด `index.html` ด้วย Chrome หรือ Edge ได้โดยตรง ไม่ต้องติดตั้งแพ็กเกจและไม่ใช้ CDN หรืออินเทอร์เน็ต

หากต้องการเปิดผ่าน local server จากโฟลเดอร์โปรเจกต์:

```powershell
py -m http.server 4173 --bind 127.0.0.1 --directory mockup
```

จากนั้นเปิด `http://127.0.0.1:4173` ข้อมูลตัวอย่างของ file URL กับ HTTP URL จะเก็บแยกกันตามเบราว์เซอร์

## ลอง flow หลัก

1. หน้าขายเริ่มต้นด้วยกะและตะกร้าตัวอย่าง เลือกสินค้า เปลี่ยนจำนวน หรือค้นหา SKU/บาร์โค้ด
2. กดรับชำระเงิน ใส่เงินสดหรือเลือกจำนวนแบบเร็ว ดูเงินทอน แล้วยืนยันการขาย
3. เปิดใบเสร็จ พิมพ์ซ้ำ หรือดูบิลเดิมจากประวัติการขาย
4. เจ้าของร้านยกเลิกทั้งบิลในกะเดิมที่เปิดอยู่ได้ โดยระบุเหตุผลและยืนยันคืนเงิน/สินค้า
5. เจ้าของร้านเปิดหน้า **คืนสินค้า** ค้นเลขบิล เลือกจำนวนรับคืนและแบ่งเป็นขายต่อได้/เสียหาย ระบุเหตุผล ตรวจยอดที่จะจ่าย ยืนยันจ่ายเงินสด แล้วเปิดหรือพิมพ์เอกสารคืนเดิมซ้ำได้ บิลเดิมยังอยู่และแสดงยอดคืนสะสม
6. ทดลองคืนต่างกะโดยปิดกะเดิม เปิดกะใหม่ แล้วคืนจากบิลเก่า: ยอดคืนจะหักในกะที่จ่ายเงิน กะเดิมไม่เปลี่ยน เลือกสถานการณ์ผลตอบกลับหายหรือบันทึกไม่สำเร็จได้ในแบบฟอร์มคืน
7. หน้าสินค้าเพิ่ม/แก้ราคา รับสินค้าเข้า ปรับเป็นยอดนับจริง และดู movement ได้
8. หน้ากะบันทึกเงินนำเข้า/ออก นับเงิน ปิดกะ และเปิดกะใหม่ได้
9. คลิกชื่อผู้ใช้มุมขวาบนเพื่อสลับเจ้าของร้าน/พนักงานขาย และดูความต่างของสิทธิ์
10. หน้าระบบเลือกสถานการณ์ขายไม่ทราบผลหรือบันทึกไม่สำเร็จ สลับออฟไลน์ ส่งออกข้อมูล และเริ่มข้อมูลตัวอย่างใหม่ได้

ปุ่มลัด: **F2** ค้นสินค้า, **Enter** เพิ่ม SKU/บาร์โค้ดที่ตรง, **F8** รับชำระเงิน, **Esc** ปิดหน้าต่าง

## ขอบเขตของตัวอย่าง

- ครบ 8 หน้า: ขาย, สินค้า/สต๊อก, ประวัติบิล, คืนสินค้า, กะ/เงินสด, รายงาน, ผู้ใช้ และระบบ/backup/audit
- คำนวณเงินด้วยจำนวนเต็มหน่วยสตางค์ ไม่ให้สต๊อกติดลบ ตรวจราคาใหม่ก่อนขาย และเก็บราคาบิลเดิม
- สถานะและข้อมูลตัวอย่างเก็บใน localStorage ของเบราว์เซอร์ รายการ checkout หรือคืนสินค้าที่ไม่ทราบผลกู้ผลเดิมได้ ข้อมูลตัวอย่างรุ่น 1 ย้ายเป็นรุ่น 2 โดยเก็บบิลและรายการเดิมไว้
- การพิมพ์ใช้ browser print ไม่ตัดสต๊อกหรือเพิ่มบิลซ้ำ
- สถานะ cloud backup เป็นการจำลอง ปุ่มส่งออกสร้างไฟล์ JSON ของข้อมูลตัวอย่าง ไม่ใช่ SQLite snapshot
- การสลับบทบาทเป็นตัวอย่าง UI ไม่มีรหัสผ่านหรือ authentication จริง การกู้คืนเป็นคำอธิบายขั้นตอน
- ยังไม่ใช่ระบบขายจริง: ไม่มี Fastify, SQLite transaction, server-side authorization, cloud upload, installation/service หรือการรับรอง offline durability ตามสเปก production
- ไม่มีส่วนลด สมาชิก บัตร/QR ต้นทุน/กำไร หรือภาษีแยก การคืนสินค้านี้เป็นเพียงขั้นทดลอง UX ตามสเปกใหม่

## ตรวจสอบ

```powershell
node --test --test-isolation=none mockup/store.test.cjs mockup/returns.test.cjs mockup/views.test.cjs
node --check mockup/store.js
node --check mockup/views.js
node --check mockup/app.js
```

ใช้ `--test-isolation=none` เมื่อ environment ไม่อนุญาตให้ test runner สร้าง process ย่อย
