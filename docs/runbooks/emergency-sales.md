# Runbook: ขายฉุกเฉินเมื่อเครื่องหลักใช้งานไม่ได้

ค่าที่ใช้วางแผน (D6 ยังรอยืนยันกับเจ้าของร้าน): **จดมือแล้วบันทึกย้อนหลังหลัง restore**

## เมื่อเน็ตล่มอย่างเดียว

ขายต่อได้ตามปกติ ระบบทำงานในเครื่อง การส่ง backup นอกเครื่องจะค้างและส่งเองเมื่อออนไลน์ หน้า **ระบบ** แสดงจำนวนที่ค้าง

## เมื่อเครื่องหลักหรือดิสก์เสีย

1. หยุดใช้เครื่องนั้นทันที อย่าพยายามเปิดฐานข้อมูลจากเครื่องอื่นแล้วขายคู่กัน
2. ขายด้วยใบเสร็จกระดาษ จดต่อบิล: เวลา รายการ (SKU/ชื่อ) จำนวน ราคา ยอด เงินรับ เงินทอน
3. นับเงินในลิ้นชักตอนเริ่มและจบช่วงฉุกเฉิน
4. เมื่อมีเครื่องพร้อม ทำตาม [restore](restore.md)
5. เปิดกะใหม่ด้วยเงินที่นับได้ แล้วบันทึกบิลกระดาษทีละบิลในหน้า **ขายสินค้า** (เวลาในระบบจะเป็นเวลาบันทึก ให้จดเลขบิลกระดาษไว้ในสมุด)
6. ปิดกะ เทียบยอดกับเงินจริง และตรวจสต๊อกสินค้าที่ขายช่วงฉุกเฉิน

## เมื่อหน้าจอแจ้ง "บิลก่อนหน้ายังไม่ทราบผล"

1. กด **ตรวจผลอีกครั้ง** ก่อนเสมอ
2. ถ้าระบบแจ้งว่ายังไม่ได้บันทึก กด **ส่งรายการเดิมอีกครั้ง** (ปลอดภัย ไม่ขายซ้ำ)
3. ถ้าเชื่อมต่อระบบไม่ได้เลย ตรวจว่า server ทำงาน (`Get-ScheduledTask BaandeePOS`) แล้วลองใหม่
4. ใช้ **ทิ้งรายการนี้** เฉพาะเมื่อแน่ใจว่าบิลไม่ได้บันทึกและลูกค้าไม่ได้ซื้อแล้ว
