# Runbook: ปิดกะ

1. ขายบิลสุดท้ายให้เสร็จ ตรวจว่าไม่มีแถบ "บิลก่อนหน้ายังไม่ทราบผล" ในหน้าขาย
2. เจ้าของร้านบันทึกเงินนำเข้า/ออกที่ยังไม่ได้บันทึก (หน้า **กะและเงินสด**)
3. นับเงินในลิ้นชักทั้งหมด
4. กด **ปิดกะ** ใส่ยอดที่นับได้ แล้วยืนยัน ระบบคำนวณยอดคาดหวังบน server ณ เวลาปิด
5. ตรวจส่วนต่าง ถ้าไม่เป็นศูนย์ให้จดเหตุผลในสมุดกะ (กะที่ปิดแล้วแก้ไม่ได้)
6. ระบบสร้าง snapshot หลังปิดกะเอง ตรวจที่หน้า **ระบบและสำรองข้อมูล** ว่าสำเร็จ

ยอดคาดหวัง = เงินตั้งต้น + ยอดขาย − ยอดยกเลิก + เงินนำเข้า − เงินนำออก

ถ้ากดปิดแล้วหน้าจอค้าง/ขึ้น error ให้กดปิดอีกครั้งด้วยยอดเดิม ระบบคืนผลการปิดเดิมโดยไม่ปิดซ้ำ
